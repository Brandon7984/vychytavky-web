# Vychytávky web

Web s praktickými nápadmi, jednoduchými projektmi a drobnými zlepšeniami pre každodenný život.

Cieľom je prinášať zrozumiteľné a realizovateľné nápady z oblastí ako:

- domácnosť a organizácia,
- dielňa a DIY,
- drevo, papier a ďalšie materiály,
- záhrada,
- dekorácie a drobné doplnky,
- praktické zlepšováky, ktoré šetria čas alebo spríjemnia život.

Projekt má byť prístupný aj ľuďom, ktorí sa nepovažujú za domácich majstrov. Dôraz je na jednoduchosti, praktickosti, peknom spracovaní a jasnom postupe.
